## Sources considered but not acquired

- Accounts XBRL bulk product: potentially useful financial statements, but taxonomy harmonisation, publication timing and missing filed details require a separate financial-data study.
- Company profiles, officers, PSC, officer appointments, filing histories, insolvency endpoints: require API access or much larger specialised bulk products. No credentials supplied; no fabricated histories substituted.
- ONS postcode directory: would enable an actual administrative-region join. This release stays explicitly at postcode-area grain.
- Bank of England and Insolvency Service aggregate series: useful macro context but cannot label individual companies or improve this cross-sectional index without stronger linkage and temporal design. Not added decoratively.

The sample contains a legitimate legacy R-prefixed registration identifier; the format validator preserves it. Existence of this identifier was checked on the official register: https://find-and-update.company-information.service.gov.uk/company/R0000055 . No current-status claim relies on that cached page.
